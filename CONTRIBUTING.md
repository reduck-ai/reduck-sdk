# Contributing

## Setup

```bash
pnpm install
pnpm build   # generates src/generated/ from openapi.json, then compiles to dist/
pnpm test    # unit tests, no network
```

To call the live API with your own key:

```bash
REDUCK_API_KEY=<your key> pnpm smoke
```

## How the code is made

`src/generated/` is generated by [@hey-api/openapi-ts](https://heyapi.dev) from
`openapi.json`, and is not committed. Only `src/client.ts` and `src/index.ts` are
written by hand. Do not change a generated function: the change goes into the
API, and comes here with its spec.

`openapi.json` is a copy of `https://reduck.ai/api/openapi.json`, with its keys
sorted. To update it:

```bash
pnpm update-spec
```

## Releases

- When Reduck releases its API, the **Update spec** workflow opens a pull
  request with the new `openapi.json`. It also runs each day. Its description
  lists the breaking changes, if any.
- Each merge into `main` that changes the package runs **Publish**. It
  increases the version that npm holds: major for a breaking change of the
  spec, minor for another change of the spec, patch for the rest. For a
  breaking change of `src/client.ts`, run **Publish** by hand and choose
  `major`.
- The version is not committed. npm and the tag `v<version>` hold it.
- **Publish** stages the version on npm: it cannot be installed until a
  maintainer approves it, on npmjs.com or with `npm stage approve <id>`
  (`npm stage list` shows the waiting ones). The approval asks for 2FA.
